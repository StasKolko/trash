Цель: разработать UI image kit под бизнес задачи.

Стек: next js 16.0.3, react-image-crop, shadcn-ui

Задачи:

1) Где распологать все файлы:

- src/shared/ui/image-kit/

2) Стурктура папки будет такой:

- index.ts
- _COMPONENT_NAME

Все файлы будут называться по принципу file-name.extensiton

А в каждом компоненты файлы стоит разбивать по принципу SRP.

3) Первый компонент будет инпутом изображений:

- props:

- - Одна картинка или множество? (по умолчанию одна)
- - Разрешенные расширения?{ png: boolean, webp: true, jpeg: boolean, jpg: boolean } (По умолчанию все разрешенны, здесь можно передать конкретное поле с false чтобы его выключить)
- - Формат? (По умолчанию сверху есть селект с выбором: 1x1, 3x4, 4x3, 16x9, 9x16 и красивая рамка с цветом tailwind primary, border-primary которая показывает как выглядит разрешение (горизонтальная или вертикальная камка форматом как в селекте). Но если переданно пропсом конкретный формат, то есть рамка этого формата, сам формат, но без селекта, селект скрыт (добавь горизонтальные размеры для банеров интернет магазина, штуки три основные)) 
- - callback куда передается итоговый список crop картинок
- - isActive (open, isOpen, isHidden, hidden, active - выбери самый лучший и семантически верный) (управляет видимостью)
- - disabled (isDisabled - как правильнее) (управляет дизеблем кнопки)

Что-то упустил может быть из пропсов?

- Логика:

- - Изначальна рамка кропа начинается с верхнего левого угла впритык
- - Изначальна рамка кропа занимает минимальную из сторон: высота, ширина. Занимая всю площадь.
- - Множество картинок коррекно и визуально разделены.
- - Картинки вызываются в виде Алерт диалога, чтобы его можно было закрыть только кнопкой defult варианта с надписью (готово, ок или придумай более коретное) в самом низу диалога. esc, клик на оверлей не должны закрывать алерт диалог.
- - Сам диалог занимает 90% ширины экрана, макисмум 1024px, минимум(90vw, 512px).
- - Картинки занимают свой настоящий размер, но превышающий ширину диалога
- - Вверху рядом с селектом форматов есть кнопка лупы (или подбери более коректную) (по умолчанию не активна), если ее нажать то все маленькие картинки растянутся на всю ширину (или высоту, самыу свою большую сторону. Только те картинки что меньше размеров диалога, например 16px, 32px и так далее)
- - При нажатии нижней кнопки (готово, ок или придумай более коретное) кнопка дизеблется, у нее кружится лоадер тейилвинд. На самих картинках появляется (на каждой в центре) появляется надпись (Обработка или подождите придумай коретное) (ннужно оверлейм оттенить от картинко, чтобы оверлей был прозрычный ми видно было и кроп рамки и картинки)
