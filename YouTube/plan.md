## 2. Что такое «товар» в контексте нашей работы

Товар — это не одна простая карточка. Каждый товар может включать в себя целый комплекс работы:

| Составляющая | Описание |
|---|---|
| **Основная карточка** | Название, описание, цена, артикул |
| **Размеры (комплектации)** | У одного товара может быть множество размеров (S, M, L, XL и т.д.) — каждый размер = отдельная единица учёта |
| **Цвета** | Один товар может быть представлен в нескольких цветах — каждый цвет может требовать отдельных фотографий |
| **Изображения** | Фотографии / генерация картинок для каждого цвета и ракурса |
| **Характеристики** | Набор фильтруемых свойств (см. раздел 3) |

> **Вывод:** одна «сущность товара» на практике может потребовать создания множества вариаций, загрузки нескольких изображений и заполнения характеристик. Норма выкладки: **10–20 товаров в день**.

---

## 3. Характеристики — отдельная критическая сущность

### Что это

Характеристики — это свойства товаров, по которым покупатель фильтрует каталог. Примеры:

- **Категория** — пальто, куртки, верхняя одежда и т.д.
- **Сезон** — зима, лето, демисезон
- **Материал** — хлопок, полиэстер, шерсть
- **Пол/аудитория** — мужчинам, женщинам, детям
- и другие

### Проблема

На данный момент в системе **ReadyScript** характеристики работают **криво** — проблема связана с **уникальным идентификатором (ID)** характеристик. Из-за этого:

- Характеристики дублируются или конфликтуют
- Фильтрация в каталоге работает некорректно
- Невозможно нормально привязывать свойства к товарам

**Эта проблема является блокирующей** — пока она не решена, выстраивание правильной структуры каталога невозможно.
