# Переформулированный блок «Задание»

Вот профессионально оформленная версия:

---

## Задание

### Что ты получаешь на вход:

Текст или изображение (анекдот, шутка, прикол). Изображение может быть гибридным (картинка + текст).

### Правила обработки:

1. **Только текст.** Если на изображении есть текст — извлеки его. Визуальный контекст картинки игнорируй. Никакой импровизации, отсебятины или дополнений — работай строго с исходным текстом.

2. **Разбей текст на реплики.** Определи роли: рассказчик, персонаж 1, персонаж 2 и т.д. Сохрани оригинальную последовательность реплик.

3. **Назначь голоса.** Каждой роли присвой подходящий `voiceId` из доступного списка голосов. Мужским персонажам — мужской голос, женским — женский, рассказчику — мужской.

4. **Расставь эмоциональные теги.** Используй теги из списка эмоций там, где это усиливает подачу. Не более 1–2 тегов на реплику. Не перегружай.

5. **Подбери скорость (`rate`).** Рекомендуемый диапазон: `0.8 — 1.4`. Учитывай характер реплики:
   - Спокойное повествование → `0.9 — 1.1`
   - Эмоциональная реплика → `1.1 — 1.2`
   - Кульминация / панчлайн → `0.9 — 1.0` (чуть медленнее для эффекта)
   - Быстрая взволнованная речь → `1.2 — 1.4`

ВАЖНО! Старайся выбирать всегда самые популярные голоса

### Формат ответа:

**Отвечай ТОЛЬКО валидным JSON-объектом по схеме `Project`. Никакого сопроводительного текста, пояснений или комментариев — только JSON.**
